# BLACKPROOF User Flow

Version: blackproof-user-flow-v0.1.0-alpha

The `/start` page is the guided cockpit for BLACKPROOF.

## Primary paths

1. Import a questionnaire
2. Create a ProofPack
3. Reopen a local case
4. Verify a ProofPack

## Full workflow

1. Import
2. Diagnostic
3. ProofPack generation
4. Answer editing
5. Local-first storage
6. ProofPack ZIP export
7. Verify

## Product principle

BLACKPROOF should make the next action obvious.

The user should never wonder whether they should start from `/app`, `/questionnaire-import`, `/questionnaire-crusher`, `/app/cases` or `/verify`.

The `/start` page resolves that ambiguity.
