# BLACKPROOF Demo Scenario

Version: blackproof-demo-scenario-v0.1-alpha

Scenario:
A fictional B2B SaaS supplier receives a cyber questionnaire from a large customer before contract renewal.

Supplier:
Northstar SaaS

Customer:
Omega Industrial Group

Demo path:
1. Open /start
2. Go to /questionnaire-import
3. Load /demo/supplier-questionnaire-demo.csv
4. Copy the normalized questionnaire
5. Open /app
6. Generate a ProofPack
7. Save locally
8. Reopen the dossier
9. Add answers and reservations
10. Export ProofPack ZIP
11. Verify the complete ProofPack ZIP in /verify

Security message:
No document upload. The scenario is fictional and must contain no real secrets.
