# Qualified application scope

BLACKPROOF is a free local application under AGPL-3.0-only. The supported flow
is questionnaire import, encrypted local dossier, reviewed Delivery export and
local verification.

Chrome and Edge Desktop are qualified. Other browsers and mobile are not yet
qualified. Return Pack generation and the cross-case Knowledge Vault remain
disabled by default because their independent functional qualifications are
incomplete; these are technical feature boundaries.

Do not enable those features as part of a distribution or hosting change.
`PUBLIC_BLACKPROOF_RETURN_PACK_ENABLED` and
`PUBLIC_BLACKPROOF_KNOWLEDGE_VAULT_ENABLED` are development switches only until
their reviewed qualification is complete.
