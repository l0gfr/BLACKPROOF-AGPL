# BLACKPROOF Framework Mapping

Version: blackproof-framework-mapping-v0.1.0-alpha

The Framework Mapping connects:

- questionnaire category
- working requirement
- expected evidence
- proof debt
- remediation action

## Important limitation

This is not a legal mapping.

It is a BLACKPROOF evidence-first working map.

It does not certify NIS2, ReCyF, ISO 27001 or any other framework.

## Current frameworks

- nis2-eu: NIS2-inspired risk-management families
- recyf-fr: France country-pack alpha
- blackproof-custom: unmapped/custom questions

## Current families

- access-control
- backup
- incident-response
- business-continuity
- supplier-security
- governance
- logging-monitoring
- vulnerability-management
- data-protection
- unknown

## Rule

A requirement is only useful if it points to evidence and to a proof debt when evidence is missing.

BLACKPROOF therefore maps requirements to evidence templates, not to abstract compliance claims.

## Product language

Say:

BLACKPROOF helps structure an evidence dossier aligned with NIS2/ReCyF-style expectations.

Do not say:

BLACKPROOF certifies NIS2 compliance.
